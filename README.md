Homebrew Tap for mozership
==========================

Casks for the tools of [mozership](https://github.com/mozership).

```bash
brew install mozership/tap/probe
```

| Cask | Description |
|---|---|
| [probe](https://github.com/mozership/probe) | End-to-end checks over HTTP, gRPC, SQL, mail and SSH from one YAML workflow |

The files under `Casks/` are written by GoReleaser when a tool is released. Do not edit them by hand.
